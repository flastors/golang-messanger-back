## Проект "Мессенджер"

Как запустить:
1. Клонируйте репозиторий:
   ```
   git clone
    ```
2. Перейдите в директорию проекта:
3. Откройте терминал и выполните команду:
   ```
   docker compose -f infrastructure/docker-compose.local.yaml up --build
   ```

Конфигурация проекта находится в директории config. Перед запуском убедитесь, что все необходимые переменные установлены.
Параметр host для базы данных меняется динамически в файле docker-compose.local.yaml в зависимости от того, где запущен проект (локально или в контейнере).

Миграция для БД происходит автоматически при старте контейнера с приложением.
Для отката миграций используйте команду (с заранее установленным goose):
```
goose down
```
Но перед этим нужно создать файл .env в корне проекта по примеру .env.example (параметры уже заданы)

В проекте есть один файл для теста usecase'ов:
- internal/app/messenger/usecase/usecase_test.go

Проверку работы API выполнял с помощью файла `test_chat.http` (плагин REST Client для VS Code).

В проекте реализовано:
- Простое логирование запросов и ошибок
- Работа с базой данных PostgreSQL с помощью GORM (смотреть internal/adapters/)
- Разделенная бизнес-логика (смотреть internal/domain/chat)
- Маршрутизация запросов с помощью chi router (сервер работает с помощью net/http)
- Сборка проекта с помощью Docker и Docker Compose
- Миграции базы данных с помощью goose
- Мониторинг и сбор метрик с помощью Prometheus и Grafana
- Открытая документация API с помощью Swagger (http://localhost:8080/swagger/)
- Добавлены CORS заголовки для поддержки кросс-доменных запросов
- Grafana находится по адресу http://localhost:3000 (логин и пароль по умолчанию: admin/admin)
